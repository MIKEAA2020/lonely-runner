## 1. The closed-form filler characterization X(S) (item 1)

THEOREM.  Let S be a finite set of positive integers, g in (0,1/2)
rational, g_S(t) = min_{s in S} ||s t||.  With

    E(S) = { t : g_S(t) > g }   (escape set; finite union of open
                                 intervals (alpha_j, beta_j)),
    L(S) = { t : g_S(t) = g }   (level set; finite, contains the
                                 interval endpoints),

for an integer x >= 1, x not in S:

    gap(S + {x}) = g  <=>  (A) and (B)

    (A) [kill]   for every escape interval there is an integer m_j with
                 m_j - g <= x*alpha_j  and  x*beta_j <= m_j + g
                 (equivalently x*(beta_j - alpha_j) <= 2g and the interval
                 [x*beta_j - g, x*alpha_j + g] contains an integer);
    (B) [touch]  some t in L(S) has ||x t|| >= g.

Consequences: cores with gap(S) > g have FINITE filler lists with the
explicit radius R(S) = floor(2g / max_j (beta_j - alpha_j)); gap(S) = g
cores have infinite families (x clean at a level time); gap(S) < g cores
have none (never occurs in zoo regimes: LRC for <= 7 speeds gives
gap >= 1/(m+1) > 2/(2m+3)); fillers BIND only at level times of the core.

Worked example (hub H2 = (1,4,5,6,7,11), g = 2/15): escape intervals
(32/105, 14/45) and mirror, length 2/315, R = 42; level set
{32/105, 14/45, 7/15, 8/15, 31/45, 73/105} with 7/15 the isolated level
time where {4,11} bind; kills leave {3,10,13,16,26,39}; the touch prunes
x = 13 (7*13 = 91 = 1 mod 15); X(H2) = {3,10,16,26,39} = brute force
exactly, and no filler exists beyond the provable radius 42.

Verification (lrc_xs_theory.py + lrc_xs_batch.c, exact arithmetic):
  V1  all 612 zoo cores (every (k-1)-subset of every zoo member at
      n = 5,6,7,8): X_theory == X_brute on [1,70], zero mismatches;
  V2  480 random cores above the rung (n = 5..8): same;
  V3  degenerate regimes behave as stated;
  V5  C brute (solve() verbatim from the sweep solver) triple-checked
      against the independent Python implementations.
The ladder decomposition of the zoos is now a theorem: every zoo member
is core + filler with the filler in X(core).

## 2. The n = 8 @ V = 50 inter-rung hunt (item 2)

Method.  v4 of the solver (lrc_ilp_check_v4.c): solve(), enumeration,
records, tight/rung2/interrung emission and sampling are UNTOUCHED from
v3; v4 adds a probe-lemma filter: gap(v) >= min_j ||v_j t0|| at any fixed
probe time, so if any of the solver's own candidate times certifies a
value > theta (theta = 2/15), the vector's gap is > theta and the full
solve is skipped.  Everything <= theta -- tight 1/9, inter-rung
(1/9, 2/17), rung values k/(8k+1) <= 6/49 -- stays exact.  The filter
skipped 99.9985% of vectors; the whole census ran in 213 s single-core
(8 shards).

Validation: (i) full V = 38 range: tight/rung2/interrung files and the
exact bottom spectrum (1,565 vectors <= 2/15) identical to v3; shard-level
outputs byte-identical (2.84 s vs 215.27 s on the same shard); (ii) V = 50
sub-range: filtered vs unfiltered byte-identical censuses and samples
(1.62 s vs 169.54 s); (iii) 5,384/5,384 sample records re-verified against
the independent Python reference; (iv) accounting exact:
spectrum + filtered = 536,878,650 = C(50,8).

Results (n8_V50_analysis.txt, all checks pass):

## 3. The standalone rung-family note (item 3)

"rung family note.pdf" (12 pages; source note_rung_family.tex in
computational-check/): a self-contained write-up of

  Theorem 1 (rung family): for all n >= 2, k >= 1,
      gap(1,...,n-1,kn) = k/(kn+1);
    for k >= 2 the argmax set is EXACTLY {k/(kn+1), (kn+1-k)/(kn+1)},
    binders exactly {1, kn}, every other runner >= (k+1)/(kn+1);
    NO coprimality condition.  The equality case runs: gap multiset
    {1/D, k/D x n} -> no mixed configurations -> set equality
    {jm mod D} = {0..n} -> NO-WRAP INDUCTION (sigma(j+1) = sigma(j) + m
    never wraps because sigma(j) + m <= 2n <= D - 1 for k >= 2) -> m = 1.
    This closes the gcd-degenerate case (e.g. n = k = 3) left open in the
    previous audit; the old sum argument needed gcd(n(n+1)/2, kn+1) = 1,
    which in fact always divides k - 1.
  Theorem 2 (base rung k = 1): gap(1..n) = 1/(n+1) with argmax set the
    UNITS grid {a/(n+1) : gcd(a, n+1) = 1} (phi(n+1) maximizers) -- the
    structural dichotomy with k >= 2 is exactly D >= 2n+1.
  Theorem 3: the filler characterization above, with proof, the H2 worked
    example, and the verification summary.
  Plus: the V = 50 census (tables of the zoos and the spectrum bottom),
  the machine-verification summary, and open problems (the n = 8
  inter-rung theorem; rung-zoo structure; n = 9 predictions).

Machine check (lrc_rung_family_check.py, extended): n = 2..16, k = 1..12
(180 pairs): value, EXACT argmax set, binders {1, kn}, slack
>= (k+1)/(kn+1) -- ZERO failures, including all gcd-degenerate pairs.
